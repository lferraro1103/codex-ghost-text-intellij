<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Editor selection/document → resolver | User/editor-controlled UTF-16 offsets and possibly stale PSI enter plugin code. |
| Selected source text → notification/test/log surfaces | Proprietary source must not be copied into UI, logs or persistent plugin state. |
| Action dispatch → document | A command triggered from popup/Keymap must not mutate the file in Phase 1. |
| Gradle/JetBrains repositories → build outputs | Build plugins, IDE artifacts and wrapper distribution are downloaded into the trusted build. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering / Denial of Service | `SelectedCommentResolver` | medium | mitigate | Bounds-check start/end/textLength, treat missing/stale PSI as invalid, use end-exclusive UTF-16 ranges and cover malformed cases in light tests. |
| T-01-02 | Information Disclosure | action notification and diagnostics | medium | mitigate | Use fixed UI strings only; retain no source in action fields and never log/interpolate selected text. |
| T-01-03 | Tampering | `GenerateCodexGhostTextAction.actionPerformed` | high | mitigate | Revalidate every execution, omit write-command/document APIs, and assert before/after document equality on valid and invalid paths. |
| T-01-04 | Tampering / Elevation of Privilege | Gradle dependency/wrapper supply chain | high | mitigate | Use official repositories, exact coordinates, verified Gradle distribution SHA-256, generated wrapper files and Plugin Verifier before use. |
| T-01-05 | Denial of Service | action `update()` hot path | medium | mitigate | BGT, bounded selected-range inspection, exactly two PSI boundary lookups, no whole-file traversal, I/O, process or notification. |
| T-01-06 | Spoofing | duplicate/custom shortcut command | low | accept | One static stable action ID is owned by IntelliJ ActionManager/Keymap; the plugin introduces no secondary dispatcher. |
