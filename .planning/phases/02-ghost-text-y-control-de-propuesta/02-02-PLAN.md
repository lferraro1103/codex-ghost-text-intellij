# Tab/Esc arbitration and native fallback

## Objective

Install application-scoped Tab/Esc action wrappers that consume only a fresh preview in its owning editor and otherwise preserve native IDE behavior.

## Tasks

1. Add one application service installer that wraps current `EditorTab` and `EditorEscape` handlers once, routes by `editor.project`, and restores only its own wrapper on disposal.
2. Enforce native lookup/live-template precedence; Esc cancels a current proposal; every non-consumed path calls the original handler with unchanged editor/caret/data context.
3. Add narrow handler-routing tests and run full platform tests/build/verifier.

## Must Haves

- No preview, wrong editor, stale proposal, active lookup or live template delegates original Tab/Esc.
- Esc cancels without a document edit; document/editor switch and release discard preview.
- Human visual UAT stays deferred and is not presented as passed.

## Threat Model

| ID | Threat | Severity | Mitigation |
|---|---|---|---|
| T-02-04 | Plugin suppresses native editor controls | high | Global wrapper delegates captured original on every non-consumed path. |
| T-02-05 | Closing one project breaks handlers of another | high | Single application service owns wrappers; conditional restoration only. |
